✅ Improvements Made

  • Page Title Integration: Filenames now use the actual page title instead of just URL paths
  • Smart Fallback: If title is unavailable, falls back to URL path-based naming
  • Character Cleaning: Removes special characters and converts spaces to hyphens
  • Length Limiting: Truncates titles to 50 characters to keep filenames manageable
  • Visual Feedback: Shows when page title is successfully loaded
  • Content Script Integration: Uses content script to get more accurate page information
